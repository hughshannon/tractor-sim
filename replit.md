# Running Tractor Farm on Replit

Click **Run** to start the Vite development server. The app is served on port
5000 and is configured to bind to all interfaces so it can load in Replit's
preview.

For local development, run `npm ci` once, then `npm run dev`. The project uses
Node.js 22. No secrets or external services are required.

To check the project, run `npm run typecheck`, `npm test`, and `npm run build`.
